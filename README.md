## 🧪 RESEARCH_OVERVIEW
I am an **AI Research Analyst** at **Ideas91**, specializing in building high-fidelity RAG (Retrieval-Augmented Generation) pipelines, computer vision systems, and intelligent automation workflows. My work focuses on translating complex AI research into scalable, production-ready solutions.

### 🔭 CURRENT_PROJECTS
- **Neural Lab Terminal**: A React-based high-fidelity terminal emulator showcasing system telemetry and interactive research modules.
- **Multimodal RAG Pipelines**: Architecting systems that merge document OCR (YOLOv8) with semantic search (FAISS/ChromaDB).
- **Embedded Agent Simulations**: Lightweight, browser-based AI simulations using HuggingFace and SentenceTransformers.
